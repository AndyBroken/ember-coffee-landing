# Ember Coffee Co. — Basic Package (Concept)

One-page landing site for a neighborhood coffee shop in Austin, TX.

**Includes:** sticky header + mobile menu, hero, features, story, tabbed menu with prices, photo gallery, reviews, opening hours (highlights today), Google Map, catering request form with validation, scroll animations. Fully responsive.

**Tech:** HTML5, CSS3, vanilla JavaScript — a single file, no build step. Photos: Unsplash.

*Concept / demo project — Ember Coffee Co. is a fictional brand.*
